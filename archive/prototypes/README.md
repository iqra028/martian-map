# Prototype Archive

This directory archives early prototype and duplicate files from the initial project setup:

1. `map.html`: Earlier prototype of the 2D Leaflet map created during initial tile service integration. Superseded by `index.html`, which contains the active application entry point, updated imagery credits, and the USGS FeatureServer query.
2. `map_resources.html`: Verified by SHA-256 hash comparison to be 100% byte-identical to `index.html`. Archived to eliminate confusing duplicate entry points at the repository root.

The active application entry point is `index.html` at the repository root.
